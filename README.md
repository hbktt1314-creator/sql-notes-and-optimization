## 文档记录建议

新增内容时，尽量说明：

1. **业务背景与问题**：要解决什么问题，结果口径是什么。
2. **数据特点与边界**：数据规模、重复值、空值和时间范围等。
3. **解题思路**：解释查询逻辑及关键 SQL 特性。
4. **SQL 示例**：标明适用的数据库或计算引擎，注明必要的表结构。
5. **验证与优化**：记录结果校验方式、执行计划、性能变化和注意事项。

## 目标

- 让 SQL 经验与优化思路可复用、可持续维护。
- 沉淀数据仓库建设中的架构、建模与治理实践。
- 通过经典案例提升复杂数据问题的分析和解决能力。

> SQL 语法和执行行为可能因数据库或计算引擎而异；运行示例前请结合实际环境验证。
